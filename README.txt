このフォルダに以下のファイル名で効果音（mp3推奨）を配置してください。
script.js から相対パス assets/sounds/◯◯.mp3 で読み込まれます。

word.mp3        … 単語が表示された時
correct.mp3      … 正解（うんちタップ成功）時
miss.mp3         … お手つき（誤タップ）時
win.mp3          … 勝敗が決まった時（ひとりプレイ完走／対戦の勝利）
highscore.mp3    … ハイスコア更新時

ファイルが無くてもゲームはエラーにならず進行しますが、
無音になります（script.js内でtry/catchしています）。
